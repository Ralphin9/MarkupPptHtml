# ⌨️ Keyboard Shortcuts — MarkupPptHtml

## Editor Mode

| Shortcut | Action |
|----------|--------|
| `F5` | Start Presenter Mode |
| `Ctrl + S` | Save project |
| `Ctrl + D` | Duplicate current slide |
| `Delete` / `Backspace` | Delete selected element |
| `Alt + ↑` | Move selected element up |
| `Alt + ↓` | Move selected element down |
| `Escape` | Deselect current element |
| `← Arrow Left` | Previous slide (when no element selected) |
| `→ Arrow Right` | Next slide (when no element selected) |

## Presenter Mode

| Shortcut | Action |
|----------|--------|
| `→` / `Space` / `Enter` | Next slide |
| `←` / `Backspace` | Previous slide |
| `Home` | Jump to first slide |
| `End` | Jump to last slide |
| `Escape` | Exit presenter mode |

## Tips

- Keyboard shortcuts for **Delete**, **Move**, **Arrow navigation**, **Duplicate**, and **Escape** are disabled when a text input or textarea is focused.
- **F5** and **Ctrl+S** work regardless of focus.
- Use the **Templates** button (or Slide Templates in the left panel) to insert pre-built slide layouts.
- Drag & drop images from the Image Gallery onto the canvas or into compare/grid drop zones.
