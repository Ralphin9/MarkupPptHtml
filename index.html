🎤 Script → Video

Generates voiceover via OmniVoice (HF Space), maps each sentence to a HyperFrames-style scene (script-to-video-skill), and adds a new slide with the timed composition.
Local install: pip install omnivoice then omnivoice-demo --ip 0.0.0.0 --port 8001
Local CPU OmniVoice is private and free, but slow: even short scripts can take a few minutes. Use the Hugging Face Space or a GPU machine for longer narration.
Your file’s audio is used directly — no TTS synthesis is run.
